# Информационная система управления товарами и заказами (Демоэкзамен КОД 09.02.07)

## 1. Описание проекта
Веб-приложение для учета складских остатков, управления ассортиментом товаров, фильтрации и оформления заказов с разграничением прав доступа (RBAC).

## 2. Учетные данные для демонстрации
| Роль | Логин | Пароль | Доступные действия |
| :--- | :--- | :--- | :--- |
| **Администратор** | `admin@shop.ru` | `AdminSecure2026!` | Каталог, CRUD товаров, Заказы (просмотр, редактирование, удаление) |
| **Менеджер** | `manager@shop.ru` | `Manager2026!` | Каталог, Просмотр заказов |
| **Клиент** | `client@shop.ru` | `Client2026!` | Просмотр каталога, поиск, фильтрация |
| **Гость** | Кнопка «Войти как гость» | — | Просмотр каталога |

## 3. Требования и запуск
- **Python**: 3.9+
- Установка зависимостей:
  ```bash
  pip3 install -r backend/requirements.txt
  ./start.sh
  # или python3 -m uvicorn backend.main:app --port 8000

  Адрес в браузере: http://0.0.0.0:8000
